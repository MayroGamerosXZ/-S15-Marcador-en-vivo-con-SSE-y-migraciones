Sistema en Tiempo Real • SSE & Drizzle ORM

Manual de Operación & Suite de Pruebas

Guía interactiva para desplegar, operar y validar el cumplimiento del 100% de los requerimientos técnicos del Marcador en Vivo.

🚀 1. Secuencia de Despliegue en Local

Sigue estos 4 pasos en tu terminal (PowerShell o CMD) dentro del directorio del proyecto:

  1. Levantar el contenedor PostgreSQL (Docker)

    Inicia el contenedor en segundo plano en el puerto dedicado 5433:

    docker compose up -d
  2. Aplicar las Migraciones Versionadas de Drizzle

    Ejecuta las dos migraciones de la carpeta drizzle/ en la base de datos:

    npm run db:migrate
  3. Sembrar Partidos y Eventos Iniciales (Seed)

    Puebla la BD con Real Madrid vs Barcelona, Man City vs Liverpool y Bayern vs Dortmund:

    npm run db:seed
  4. Iniciar la Aplicación Completa (Frontend + Backend)

    Inicia el servidor Express (puerto 3001) y la interfaz Vite (puerto 5173) en paralelo:

    npm run dev
🌐 Accesos rápidos en tu navegador:
• Interfaz Web de Usuario: http://localhost:5173
• API REST Backend: http://localhost:3001/api/matches

🎮 2. Manual de Operación de la Interfaz

A. Vista Pública (Modo Espectador)

Diseñada para que los aficionados sigan los partidos en tiempo real sin recargar la página.

  • Selector de Partidos: En la parte superior se muestran los partidos de la jornada. Al hacer clic en cualquiera de ellos, se sintoniza el stream SSE de ese partido.
  • Marcador En Vivo: Muestra los escudos, nombres de equipos, período (1T, 2T, etc.) y los goles en números de gran formato.
  • Badge de Estado SSE: En la esquina superior derecha del marcador se refleja el estado de la conexión en vivo: 🟢 Conectado 🟡 Reconectando... 🔴 Desconectado
  • Línea de Tiempo (Timeline): Muestra los sucesos ordenados por minuto. Cada evento tiene su propio diseño visual:
    • ⚽ Gol: Fondo verde brillante con animación de celebración y autor.
    • 🟨 Tarjeta Amarilla: Icono y badge dorado.
    • 🟥 Tarjeta Roja: Aviso de expulsión en rojo vivo.
    • ⚠️ Falta: Alerta ámbar con descripción táctica.
    • 🔄 Sustitución: Badge azul celeste con jugador saliente y entrante.

B. Panel de Administración (Modo Árbitro / Operador)

Permite registrar incidencias en tiempo real y publicarlas inmediatamente a los espectadores.

  • Navegación: Haz clic en el botón "Panel Admin" en el encabezado.
  • Plantillas Rápidas: Para agilizar pruebas, usa los botones directos como "⚽ Gol Real Madrid" o "🔄 Sustitución" que rellenan automáticamente los campos.
  • Formulario Validado: Valida minuto (1-130), equipo, tipo de evento y descripción obligatoria.
  • Flujo de Datos Garantizado: Al hacer clic en "Registrar y Transmitir Evento", el servidor realiza un POST, guarda el evento en PostgreSQL y solo entonces lo transmite vía SSE a los clientes sintonizados a ese partido.

🛠️ 4. Solución de Problemas (Troubleshooting)

¿El comando npm run db:migrate da error de conexión?
Asegúrate de que Docker Desktop esté abierto y que el contenedor esté corriendo con docker ps. Recuerda que el puerto configurado en el archivo .env es el 5433 para no interferir con otros servicios locales.
¿Cómo reiniciar la base de datos a un estado limpio?
Simplemente vuelve a ejecutar en tu terminal:
npm run db:seed
Esto limpiará las tablas e insertará nuevamente los partidos y eventos de prueba.
